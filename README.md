## 🛠️ เครื่องมือที่จะได้เรียน

- **Reconnaissance**: Nmap, Maltego, theHarvester, Shodan, Recon-ng
- **Scanning**: Nessus, OpenVAS, Nikto, WPScan
- **Exploitation**: Metasploit, SQLmap, ExploitDB
- **Web Testing**: Burp Suite, OWASP ZAP, Dirb, Gobuster
- **Password**: Hydra, John the Ripper, Hashcat, CrackMapExec
- **Network**: Wireshark, tcpdump, Ettercap, Bettercap
- **Post-Exploitation**: Mimikatz, BloodHound, Empire, Cobalt Strike
- **Wireless**: Aircrack-ng, Kismet, Wifite
- **Forensics**: Autopsy, Volatility, Binwalk
- **C2 Frameworks**: Sliver, Havoc, Cobalt Strike
- **Web3**: Web3.py, Foundry, Slither, Echidna

## 📋 ข้อกำหนดเบื้องต้น

- คอมพิวเตอร์ที่รองรับ Virtualization
- RAM อย่างน้อย 8GB (แนะนำ 16GB)
- พื้นที่ว่างอย่างน้อย 100GB
- ความตั้งใจและความพยายาม
